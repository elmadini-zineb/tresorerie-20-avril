## ÉTAPE 4 — CORRIGER le menu latéral (point le plus important)

Le menu latéral de `adria-treasury/` doit être modifié pour 
implémenter un DOUBLE menu latéral :

### Menu principal (toujours visible à gauche)

Contenu selon le rôle connecté :

TRESORIER :
  - Tableau de Bord
  - Suivi des Comptes
  - Flux Déclarés
  - Prévision Trésorerie
  - Rapprochement  ← avec chevron › et badge rouge (nb d'éléments en attente)
  - Multi-devises
  - Interface ERP/EBICS
  - Alertes
  - Reporting

ADMIN_CLIENT :
  - Tableau de Bord
  - Référentiels
  - Factures Reçues
  - Factures Émises
  - Rapprochement  ← avec chevron › et badge rouge
  - Rapports

BACKOFFICE / ADMIN_BANQUE :
  - Leurs menus respectifs, SANS item Rapprochement

### Menu secondaire (slide-in au survol de "Rapprochement")

Quand la souris survole l'item "Rapprochement" dans le menu principal,
un SECOND panneau s'affiche immédiatement à droite du premier 
par animation slide-in.

Ce second panneau est un composant React séparé (SecondarySidebar).
Il est MONTÉ/DÉMONTÉ dans le DOM selon l'état hover — 
pas un simple display:none.

Pour TRESORIER, le menu secondaire affiche :
  - Dashboard Rapprochement
  - ── Référentiels
       - Fournisseurs
       - Clients
  - ── Factures
       - Factures Reçues
       - Factures Émises
  - Rapprochement (vue active)
  - ── Rapports
       - État de Rapprochement
       - CPC
       - Déclaration TVA

Pour ADMIN_CLIENT, le menu secondaire affiche :
  - Dashboard Admin
  - File de Validation
  - Règles de Rapprochement
  - Gestion Utilisateurs
  - Paramètres Entreprise

Comportement exact du hover :
  - Le survol de "Rapprochement" dans le menu principal ouvre le 
    menu secondaire (onMouseEnter)
  - Le menu secondaire reste ouvert si la souris se déplace dessus
  - Il se ferme seulement quand la souris quitte LES DEUX menus 
    (utilise un délai de 150ms pour éviter la fermeture accidentelle 
    pendant le déplacement de la souris entre les deux panneaux)
  - Sur mobile : tap sur "Rapprochement" toggle le menu secondaire 
    en dessous, en accordion

Le badge rouge sur l'item "Rapprochement" :
  - Affiche le total de (suggestions en attente + écarts non justifiés)
  - Récupère cette valeur depuis le même mécanisme de state 
    déjà utilisé dans `adria-treasury/` (Context ou store existant)
  - Reste visible même quand le menu secondaire est fermé
